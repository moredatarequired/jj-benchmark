# Describe a Commit

## Background
In Jujutsu (`jj`), every change in the working copy is automatically recorded as a commit. Because the working copy is already a commit, its description can be set at any time — there is no need to create a new commit first.

## Requirements
- Update the change description of the current working copy commit to be exactly `"feat: add new feature"`.

## Output
- Project path: `/home/user/myproject`
